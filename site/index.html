Your money, in a chat.

WalletLedger is a personal-finance assistant that lives in Telegram: tell it what you spent in plain words, and it keeps your books.

Open the bot on Telegram View on GitHub

Prefer your own copy? Run it yourself in two commands. Curious how it works inside? Explore the code in five minutes or read the docs.

  • PDF statement import
  • SQLite or Postgres
How it works

Say it. It understands. Your books update.

Most expense apps make you open the app, pick a category and type an amount. WalletLedger lets you just say it, in Telegram, the app you already have open all day.

  1. 1

    You say it

    Type a message the way you would to a friend, or send a statement PDF.

    “Received 60000 salary in Bank”

  2. 2

    It works out what you meant

    Clear messages like “spent 200 on chai, 80 on auto” are read instantly by built-in rules, no AI needed. Questions and goals go to an AI if you added a key. Either way it picks the right action: expense, income or transfer.

  3. 3

    Your books update

    The balance changes and the transaction is saved in one safe step, then the bot replies in two lines with an Undo button. Big transfers (₹5,000 and up) ask “are you sure?” first.

Features

Everything you need to keep track, nothing you have to learn

Your accounts (cash, bank, wallets, cards) hold your money. WalletLedger keeps every one of them up to date as you chat.

  • Log by chatting

    Spending, income and transfers in plain words. Moving money from Bank to Cash is a transfer, so it never inflates your spending.

  • PDF statement import

    Send a PhonePe, GPay, Paytm, BHIM or bank statement. You see a preview of what was found before anything is saved.

  • Stats and balances

    /balance shows every account and your total. /stats shows spending against the last period, with buttons to change the period or the chart. Try /stats last month food.

  • Charts and a web dashboard

    13 chart types in the chat (categories, trend, weekdays, heatmap, merchants, net worth…). /dashboard opens a private web page, or a Telegram Mini App, with 12 interactive charts, filters and a transactions table.

  • Savings advice in 3 tones

    needs an AI key

    Advice based on your real numbers, in the tone you prefer. Pick one to see what it does:

    Advice tone

    /coach is warm and encouraging: it starts with what is going well, points out the biggest savings opportunities with real amounts, and ends with one small next step.

    /budgeter is blunt: it leads with what is costing you the most, separates needs from wants, and gives a numbered list of cuts with the monthly saving for each.

    /summary is a few quick bullet points, one line each, with the key number in bold. Made for reading on a phone.

  • Undo and confirmations

    Made a mistake? Tap Undo (or /undo). Big transfers and statement imports ask you to confirm first, so a typo can’t move a fortune.

  • Ask in plain words

    needs an AI key

    “Can I afford a ₹50,000 laptop in 5 months?” or “how am I doing this month?” The AI looks up your real numbers in a few short steps, then answers briefly. It can only use the bot’s own tools, and big transfers still wait for your Yes.

  • Savings goals

    /plan 50000 6 checks the goal against what you really earn and spend, and suggests what to trim. No AI needed.

  • Works without an AI key

    offline mode

    The AI is optional. Without a key, or if every key fails, WalletLedger carries on with built-in rules for logging, balances and reports, so it never just stops. /status tells you which mode you are in.

Bring your own key

Use the AI you already have

Everyone brings their own AI key, so there is no shared bill. It lets the bot answer free-form questions and write advice. You manage keys right in the chat; no config files needed.

  • Tested live before it is saved.

    Send /setkey with your key. A dead or mistyped key is rejected with the reason, and the bot deletes your message afterwards.

  • Optional shared key.

    An admin can add a key for everyone on the bot with /admin addkey. It is stored encrypted and never shown to users.

  • Nothing to update by hand.

    Model names are discovered automatically from each provider. /keys, /testkey, /pausekey and friends manage the rest.

Your data

Straight answers about your data

You run WalletLedger, so your data stays on the computer or server you choose. Here is exactly what is protected today and what is not.

  • Encrypted

    AI keys

    Saved AI keys are encrypted in the database. Someone who copies the database file cannot read them without the server’s secret key.

  • Encrypted

    Chat history and notes

    Your conversations and the notes on each transaction are encrypted in the database too. Older rows are encrypted once with a one-line command (scripts/protect_data.py encrypt).

  • You control it

    One database you own

    Everything lives in one place: a single SQLite file by default, or a PostgreSQL database you run. Amounts, dates, accounts, categories and merchant names are stored as readable values (the database has to add them up), so keep that file private and use disk encryption.

  • Good to know

    Not zero-knowledge

    Whoever runs the server can read the data. If you use an AI key, the AI provider receives recent messages and spending summaries to answer you.

The full list of what is stored, who can see it and how to harden it is in the security document.

Evaluation

How well does it work?

We test the agent against 50 written-down cases with exact right answers: after each message, the balances and transactions in the database must be exactly what they should be. 34 cases use the built-in rules only, 16 use a real Gemini model.

  • Rules, no AI

    33 of 34 correct (97%)

    Same result in all 3 repeat runs, with tools called directly or through the MCP server. Answers in about 10 ms.

  • With AI

    13 of 16 correct (81%)

    All free-form messages, goals and prompt-injection attempts passed. Mixed “log this and tell me that” requests are the weak spot.

  • Money safety

    0 safety violations

    Every transfer of ₹5,000 or more waited for Yes. No question was ever logged as spending. A pasted API key never reached the chat history.

  • Honest limits

    What it got wrong

    Typos can create odd categories (“lnch”), and the Coach sometimes suggests rounded savings figures that are estimates, not data.

The method, the full dataset, every metric and the raw reports are public, and anyone can re-run them.

Run your own

Set it up in 2 commands

The first start asks a few questions, writes the settings for you and checks that everything works. After that it starts straight away.

You will need:

  • Python 3.14 and uv installed
  • A bot token from @BotFather in Telegram (send /newbot)
  • Optional: an AI key. You can add one later in the chat.
In a terminal, inside the project folder
  1. 1. Install
    uv sync
  2. 2. Start the bot (the first start asks a few questions: bot token, your id, optional AI key)
    uv run uvicorn main:app --reload --port 8000

Then open your bot in Telegram and send /start. Change an answer later with uv run python scripts/setup.py; check health with uv run python scripts/setup.py --check.

FAQ

Questions people ask

Is it free?

Yes. WalletLedger is open source under the Apache-2.0 licence, and you can run it yourself at no cost.

If you add an AI key, any usage is billed by that AI provider to your own account, under their pricing. Without a key, nothing is billed at all.

Which AI providers does it work with?

Google Gemini (both AIza… and the newer AQ.… keys), OpenAI, Anthropic Claude, Groq, OpenRouter, xAI Grok, DeepSeek and Mistral. Model names are discovered automatically.

Do I need an AI key?

No. Logging spending and income, transfers, balances, reports and statement import all work with built-in rules. A key adds free-form questions and the savings advice (/coach, /budgeter, /summary).

Is my data private?

It stays in a database on the computer or server you run. AI keys, chat history and transaction notes are encrypted; amounts, dates and category names are stored readable so they can be added up. This is not a zero-knowledge design: whoever runs the server can read the data, and an AI provider sees what is sent to it when you use a key.

Details are in SECURITY.md.

Can other people use my bot?

Only if you let them. The setting ALLOWED_CHAT_IDS is the guest list: people on it can use the bot, and each person only ever sees their own data. If you leave it empty, anyone who finds the bot can use it, so set it. The setup wizard fills it in with your own id.

ADMIN_CHAT_IDS decides who can manage the shared AI keys.
